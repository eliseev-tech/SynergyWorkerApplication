# Synergy Worker Application

Учебное Spring Boot-приложение, разработанное в рамках производственной практики в Университете «Синергия».

## Описание проекта

Приложение предназначено для учета работников организации и поиска сотрудников, чей стаж работы превышает заданное пользователем значение.

В качестве основы используется класс `Worker`, содержащий информацию о работнике:

- фамилия и инициалы;
- должность;
- заработная плата;
- год поступления на работу.

Приложение реализовано в виде консольной программы с использованием Spring Boot и `CommandLineRunner`.

## Функциональные возможности

Программа поддерживает следующие операции:

1. Добавление нового работника.
2. Вывод фамилий работников, чей стаж работы превышает заданное значение.
3. Завершение работы приложения.

## Описание компонентов

### Worker

Класс `Worker` описывает работника организации и содержит:

- поля класса;
- конструктор по умолчанию;
- несколько конструкторов с параметрами;
- методы изменения и получения значений полей;
- переопределенный метод `toString()`;
- метод `destroy()` как учебный аналог деструктора.

### WorkerService

Сервисный класс предназначен для:

- хранения списка работников;
- поиска работников по стажу.

Для хранения объектов используется стандартный список `List<Worker>`.

### WorkerConsoleRunner

Компонент консольного интерфейса приложения.

Отвечает за:

- вывод меню;
- ввод данных работников с клавиатуры;
- выполнение поиска работников по стажу;
- завершение работы Spring Boot-приложения.

## Тестирование

В проекте реализованы модульные тесты для проверки работы сервиса `WorkerService`.

Тесты проверяют:

- поиск работников, чей стаж превышает заданное значение;
- ситуацию, когда подходящие работники отсутствуют.

### Запуск тестов

```bash
mvn test
```

## Соответствие заданию

В проекте реализованы основные требования кейс-задачи №3:

- описан класс `Worker`;
- добавлены поля: ФИО, должность, зарплата, год поступления на работу;
- реализован ввод данных с клавиатуры;
- для хранения работников используется `List<Worker>`;
- реализован поиск работников, чей стаж превышает значение, введенное пользователем;
- при отсутствии подходящих работников выводится соответствующее сообщение;
- класс и логика работы с ним разделены по отдельным модулям;
- добавлены модульные тесты для проверки поиска работников по стажу.
